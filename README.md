# puzzler-pro-generator
## The idea
I have an IQ Puzzler Pro, and have done all the puzzles it comes with. I want to make a website hosted on github pages which generates new puzzles for me to make.

## Features
* Make new puzzles with different difficulties (Starter, Junior, Expert, Master, Wizard). Every puzzle needs to be solvable and categorised into the difficulty brackets.
* Hints for if you cannot solve it
* Timer for if you want to time it
* Puzzle of the day
* All hosted on github pages.
